# Android Super ADB Tools

面向 Android TV 的 ADB 工具源码，用于检查设备能力，并引导用户在电视本机完成调试设置。

## 功能

- 显示 Android 版本、API 级别、电视 IPv4 地址、开发者模式、`adbd` 和 ROOT 状态。
- 打开开发者选项、无线调试和系统公开的设置页面。
- 手动浏览设置模块，使用“上一个”“下一个”“激活”操作，只有点击“激活”才会打开模块。
- 扫描系统中已导出的 Activity，尽量发现厂商自定义的电视设置入口。
- 说明 USB ADB、TCP ADB、Android 11+ 无线调试和 ROOT 相关方法及限制。
- 明确区分 ADB、`adbd`、开发者模式和 ROOT；普通 APK 不能自行授予 ROOT，也不能绕过系统权限启动被关闭的 `adbd`。

## 仓库范围

本仓库是源码快照，故意不包含 Gradle 工程文件、构建产物、APK、签名文件、密码、本机配置和生成文件。

Android 源码位于 `app/src/main`。使用前需要将这些文件放入 Android 工程。原项目包名为 `com.pctutu.adb`，最低目标 Android API 为 API 14。

## 安全说明

ADB 具有强大的设备控制能力。只应在可信局域网使用网络 ADB，并在不再需要时关闭。应用不包含或分发 `adb`、`adbd`、ROOT 管理器或第三方二进制文件。
